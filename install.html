为所有 Bangumi 用户制作

补全你的收藏，
只需几个按键。

沿动画、漫画、书籍、游戏、音乐、三次元列表快速补标。查看 Bangumi 站内评分，选择收藏状态并填写短评，也可只标记看过而不评分。记住进度，后台保存，支持自定义快捷键与滚轮。

  1. 先安装 Tampermonkey 或 Violentmonkey。
  2. 点击下方按钮下载脚本，打开油猴“管理面板 → 实用工具 → 从文件导入”，选择下载的 .user.js 文件并确认安装。
  3. 登录 Bangumi，点击右下角“快速补标”。

收藏状态自动适配「看 / 读 / 玩 / 听」。点击底部保存按钮保存状态、评分和短评，默认“不评分”：未评分作品不写入分数，已有评分保持不变；在编辑区按 Ctrl + Enter 也可保存。

未提交的编辑会保留为草稿。保存只更新修改的字段，保留原标签、隐私及未修改的收藏信息，失败任务可在面板重试。

误标了？返回上一部，在面板直接删除收藏。按钮、滚轮和快捷键都可以在设置中修改。

按钮只显示源代码或下载文件？

保存为 .user.js 文件后，进入油猴“管理面板 → 实用工具 → 从文件导入”即可，无需启动服务器。也可全选复制源码，在油猴“添加新脚本”中全选替换并按 Ctrl+S 保存。安装后若看不到入口，请检查扩展是否允许访问 Bangumi，以及是否开启“允许运行用户脚本”，最后刷新网站。

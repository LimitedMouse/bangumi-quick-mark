为所有 Bangumi 用户制作

补全你的收藏，
只需几个按键。

沿动画、漫画、书籍、游戏、音乐、三次元列表快速补标。记住进度，后台保存，支持自定义快捷键与滚轮。

  1. 先安装 Tampermonkey 或 Violentmonkey。
  2. 点击下方按钮下载脚本，打开油猴“管理面板 → 实用工具 → 从文件导入”，选择下载的 .user.js 文件并确认安装。
  3. 登录 Bangumi，点击右下角“快速补标”。

保存为 .user.js 文件后，进入油猴“管理面板 → 实用工具 → 从文件导入”即可，无需启动服务器。也可全选复制源码，在油猴“添加新脚本”中全选替换并按 Ctrl+S 保存。安装后若看不到入口，请检查扩展是否允许访问 Bangumi，以及是否开启“允许运行用户脚本”，最后刷新网站。
